# MoodScape — Same Melody, Different Emotion

## Project Overview

MoodScape is a creative coding music prototype developed using Python in TunePad. The project explores how one base melody can communicate four different emotions: Calm, Happy, Intense and Reflective.

The same eight-note melody is maintained throughout the composition, while musical characteristics such as note duration, velocity, rhythm, harmony, instrumentation and percussion are changed to create different emotional experiences.

## How MoodScape Works

The composition contains four sections:

Calm: Slow piano notes, soft chords and gentle background sounds.

Happy: Faster piano notes, brighter accompaniment and upbeat percussion.

Intense: Rapid notes, stronger dynamics, dramatic chords and powerful drums.

Reflective: Slower piano notes, pauses, soft background chords and minimal percussion.

The final composition also includes transitions between moods and a soft piano ending.

## Project Files

main_melody.py — Contains the eight-note melody and its four emotional transformations.

background_chords.py — Provides harmonic accompaniment for each mood.

background_instruments.py — Adds atmospheric sounds and musical textures.

drums.py — Controls percussion and rhythmic changes.

## How to Run the Project

Open TunePad.

Create a new project.

Add three Keyboard cells and one Drums cell.

Copy the code from each Python file into its corresponding cell.

Select the appropriate instruments used in the original composition.

Press the main Play button to hear all four emotional sections.

The code uses TunePad's built-in music functions and is designed to run in TunePad rather than standard Python.

## Instrument settings:
- main_melody.py — Piano
- background_chords.py — Piano
- background_instruments.py — Synth > Pads > Dreamy Pad
- drums.py — 808 Drumkit

Run all four cells together in TunePad.
The files use TunePad-specific functions and will not run
directly in standard Python.

## Coding Concepts

MoodScape demonstrates Python lists, variables, nested loops, note durations, velocity, rests and TunePad's built-in music functions. Multiple instrument cells are used to create layered musical compositions.

## Testing and Evaluation

The completed composition was tested with three listeners. All three generally enjoyed the piece and identified the four intended emotional sections.

The testing suggested that changes in musical characteristics helped communicate different moods while keeping the same base melody.

## Development

MoodScape was developed through experimentation, debugging, musical layering, testing and refinement. Earlier versions were retained to document the development process.
